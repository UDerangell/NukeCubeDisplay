- Prompt: Tell a story about the 4 stakeholders from the Systems Thinking paper working in a 3d spatial computing environment where each one maps their viewpoints on the 4 sides of a cube.  It is a Rubik's cube which has 9 squares on each side - the center square is larger, but they can see a sampling of other viewpoints in the other visible cubies and if can rotate them into their view to look at the problem from an adjacent perspective.  Imagine a discussion that uses this tool to improve understanding of each other's viewpoints.
